# 치이카와 다마고치

모바일 브라우저에서 즐기는 비공식 팬게임입니다. 웹 파일은 `dist/`에 있으며 별도 빌드 없이 실행됩니다.

## GitHub Pages에 게시하기

1. 이 폴더를 본인의 GitHub 저장소에 올립니다. `dist/`와 `.github/workflows/pages.yml`을 함께 올려야 합니다.
2. 저장소 **Settings → Pages → Build and deployment → Source**를 **GitHub Actions**로 설정합니다.
3. `main` 브랜치에 변경 사항을 올리면 Pages 배포가 실행됩니다. **Actions** 탭에서 결과와 게시 주소를 확인합니다.

GitHub Free에서 Pages를 쓰려면 공개 저장소가 필요합니다. 공개 저장소에 올린 게임 코드와 이미지·영상 파일은 누구나 볼 수 있습니다.

## 플레이 기록과 친구 집

플레이 기록은 각 웹 주소의 브라우저 저장 공간에 따로 보관됩니다. 현재 Sites 주소에서 GitHub Pages 주소로 옮길 때는 게임의 **저장 → 저장 파일 받기**를 누르고, 새 주소에서 **파일 불러오기**를 사용하세요.

**집 · 공유 → 내 방 공유하기**로 집 링크를 보낼 수 있습니다. 받은 링크로 방문하면 친구 집 목록에 저장되고, 내 캐릭터가 집 안을 걸으며 인사하거나 소품을 구경할 수 있습니다. 공유 링크에는 보낸 순간의 집 모습이 담기므로, 친구가 집을 다시 꾸몄다면 새 링크를 받아야 합니다. 친구 집 방문은 실시간 접속이나 공동 플레이가 아닙니다.

## 파일 구성

- `dist/`: 실제 게임과 모든 정적 자산
- `.github/workflows/pages.yml`: GitHub Pages 게시 설정
- `.openai/hosting.json`: 현재 ChatGPT Sites 게시 설정
